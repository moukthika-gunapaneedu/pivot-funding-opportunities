# RIO Live Funding Opportunity Feed (Pivot-RP)

This repository hosts a public-facing web page that displays a live, curated feed of funding opportunities for CU Boulder faculty, powered by Pivot-RP embedded searches.
Link to the website: https://moukthika-gunapaneedu.github.io/pivot-funding-opportunities/

## What this page does

- Displays **live funding opportunities** from Pivot-RP using embedded searches
- Automatically reflects updates as opportunities are added, modified, or archived in Pivot-RP
- Provides a centralized, CU Boulder–branded entry point for faculty exploring funding options

## How updates work

This page uses Pivot-RP embedded searches.

- The data shown is **live** and updates continuously as Pivot-RP changes
- There is no manual refresh or scheduled update process
- Individual opportunities may be updated at different times by sponsors or by Pivot-RP curation

## Intended audience

- CU Boulder faculty, researchers, and research staff
- RIO staff supporting proposal development and broader impacts

Access to full opportunity details may require institutional login via Pivot-RP.

## Ownership and maintenance

- The page layout and branding are maintained by the Research & Innovation Office (RIO)
- Funding data is sourced directly from Pivot-RP
- Search logic and embedded queries may be reviewed or adjusted periodically by RIO staff to improve relevance

## Technical notes

- This site is a static HTML page hosted via GitHub Pages
- Funding results are embedded using Pivot-RP iframe embeds
- No backend services, APIs, or scheduled jobs are used
